# Debug mode logging + Worker EPUB illustrations (2026-10-06)
- Request: with `webui.debug-mode` on, surface internal errors (挿絵が EPUB に入らない) in the Web console and the browser devtools console.
- Core: `application::debug` is the only entry point (`set_enabled` / `enabled` / `emit` / `emit_error` / `apply_settings` / `enabled_in_settings`, prefix `[debug]`). Lines go through `messages::emit_default`, so native puts them on the CLI/Web console and the Worker puts them on the PushHub `echo` stream. OFF = silence.
- Wiring: native `commands::convert` (web mode), `web::worker::execute_job`, `web::novels::generate_epub_on_demand`; Worker `executor.rs` (per job, covers convert) and `api_novel_download_epub` (`local_map`). During the EPUB stream there is no job sink, so `push_debug_line` posts to PushHub directly (`worker_entry/src/lib.rs`).
- Instrumented: downloader illustration grab (`illust_grep_pattern` missing / cached / stored / failures), `epub_lite::build_book_from_source` (resolved / unresolved / unsupported + `warn_illustration_missing` always), Worker EPUB listing (prefix, count, excluded names, index entries, unresolved refs, per-image read bytes).
- Web UI: `main.js` `mirrorConsoleToDevtools` forwards Web-console lines to devtools only when `State.debugMode` is true (debug → `console.debug`, stderr → `console.error`).
- **Root cause of the missing illustrations (Worker)**: the portable converter has no illustration localization (`src/converter/mod.rs` non-native path is a no-op), so the converted text keeps the site URL in the note. `download.epub` now rewrites those references to the stored `挿絵/<file>` via `.illustration_cache.yaml` (`epub_lite::rewrite_illustration_references`, URL-aware scanner `illustration_references`). Note: AozoraEpub3_Lite's own `image_references` rejects `https://…` because `normalize_image_path` drops empty path segments, so narou.rs must do its own scan (the user allowed patching the Lite crate, but narou.rs-side was enough and preferred).
- Tests: `application::debug` (3), `epub_lite` rewrite tests (3). Full workspace tests + clippy + doc are clean locally.

# Client-first novel transfer design (2026-11-15)
User explicitly requires client-first: work possible in browser must stay there. docs/client-transfer-design.md is the normative contract. Full implementation is in progress on local feature-client-transfer; it is NOT yet verified or released. Initial transfer.js posted whole ZIP and consumed server ZIP/Base64, and standalone transfer_wasm was not wired to UI; these old paths must be removed, never fallback.
Design: ESM Dedicated Worker + shipped/hash-matched WASM does ZIP generate/extract/validate; server auth/independent raw hash/path/plan validation/storage/publication only. No server-ZIP fallback. v2 sessions, <=8 MiB framed binary batches/100 records, 64 KiB codec I/O, payload=8MiB-64KiB, NDJSON wire manifest with <=32KiB text fragments. Original ZIP format2 (ordinary1 readable) unchanged. Old 512/512/256MiB streaming limits removed in planned codec, ZIP64 needed. Bounded requests address Cloudflare front-door 413 independently.
Correctness: client-issued persisted request ID+secret; creation ticket/retained replay receipt; deterministic file index; prefix digests; durable resumable stage and SHA2 0.11 checkpoints; primary-only v2 reads. Per-novel journal+reader/writer fence: close admission before drain; gate-checked renewal, object generation on chunk reads, non-stealable FS locks, S3 immutable physical versions + transactional refs (never mutable PUT precheck alone). YAML commit mark+undo/redo, Windows power-loss caveat. Transfer-owned namespace/collector and owner-bound reservations. No pool rollback delete; hash/name verified and conditional write-once. All mutating/read callers must migrate.
Default runtime projection sends current body/toc/settings/illustrations/index and preserves unknown user data, excluding raw/optional history/confirmed derived output before network and snapshot. Explicit complete preserves eligible novel data. Worker prohibits newly persisting raw; Native YAML/SQLite raw is optional maintenance material, not required merely because of storage mode. Same logical DB/FS data must appear once; no DB dumps or mirror duplication. Source ZIP/library stay unchanged. mirror=false import remains an explicitly reported legacy constraint until actually implemented.
Build/CI must ship actual WASM (lean portable feature, no accidental Lite GPL in standard), MIME/hash/ABI/worker/SW matching, real browser E2E mandatory. Reviewed design races and RTT/seal gaps are resolved in the contract; actual implementation still must pass the full acceptance matrix. No runtime success may be claimed from docs or standalone WASM alone.

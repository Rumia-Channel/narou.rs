# v0.5.0 設計メモ

対象: 非表示設定 / サイト別並列ダウンロード / 小説データの ZIP ダウンロード・アップロード。

## 1. 非表示設定

- 単位: **作品 / タグ / 作者 / サイト**。
- 非表示タグが付いた作品、非表示作者の作品、非表示サイトの作品は、作品一覧からも隠す。
- 保存: 在庫 (inventory) の `hidden` キー。
  - Native YAML: `.narou/hidden.yaml`（narou.rb 非対応の拡張ファイル）。
  - Native SQLite / Worker D1: `app_state(scope='inv', key='hidden')` を正とし、`hidden_novels` / `hidden_tags` / `hidden_authors` / `hidden_sites` の投影テーブルを保存時に全置換する。
  - 構造: `{ novels: [i64], tags: [String], authors: [String], sites: [String] }`。authors は `author_fold`、sites は `domain_fold` で比較する。
- 一覧フィルタ: `NovelFilter.include_hidden`（既定 `true`）を追加し、`false` のとき
  `NOT EXISTS hidden_novels` / `hidden_tags` / `hidden_authors` / `hidden_sites` を WHERE に足す。
  CLI/Web の作品一覧だけ `false` にし、update / clean / mail / convert など内部列挙は既定のまま（非表示作品も更新対象）。
- CLI: `narou hidden` (Rust 拡張)。
  - `hidden add <target>...`（作品）/ `--tag TAG` / `--author AUTHOR` / `--site DOMAIN`。
  - `hidden remove ...`、`hidden list`、`hidden clear [--tag|--author|--site|--novel]`。
  - `list --show-hidden` で非表示も表示。
- Web UI: 一覧に「非表示も表示」トグル。作品行のメニューから作品を非表示、タグチップ・作者・サイトからも非表示にできる。設定ページに「非表示」タブ（一覧・解除）を追加。
- Workers: 同じ API (`GET/POST/DELETE /api/hidden`) と一覧フィルタ。D1 は migration で投影テーブルを追加。

## 2. サイト別並列ダウンロード

- サイトファミリー: 同一運営のドメインを 1 グループにまとめ、グループ内は直列。
  - なろう系: `ncode.syosetu.com` / `novel18.syosetu.com` / `xmypage.syosetu.com` / `yomou.syosetu.com` / `api.syosetu.com` → `syosetu.com`。
  - カクヨム / Pixiv / ハーメルン等はドメイン単位。
  - 定義は `SiteSetting` の `parallel_group`（任意）→ 無ければドメインの登録可能ドメイン (eTLD+1 相当) を使う。
- Native CLI / Web UI: 既存の per-domain ワーカーを「per-family」に変更。異なるファミリーは同時実行、同一ファミリーは直列。
- Web UI の個別 Download ジョブ: キュー worker が異なるファミリーのジョブを同時実行できるようにする（同一ファミリーはロックで直列）。
- Workers: Queue consumer のバッチ内で、異なるファミリーのメッセージを並行実行する。同一ファミリーは in-isolate の排他 + 台帳で直列化。`wrangler.toml` の `max_concurrency` も必要に応じて設定。
- 既存のレートリミッタ・凍結・ロックはファミリー単位で維持する。

## 3. 小説データの ZIP ダウンロード / アップロード

- 単位: 選択した作品ごとの ZIP（複数作品を 1 ZIP にまとめてよい）。
- ZIP 内容: `manifest.json` + `novels/<id>/...`。
  - 本文 YAML、`toc.yaml`、`setting.ini`、`replace.txt`、`converter.yaml`、`挿絵/`、EPUB、`*.yaml` の付帯ファイル。
  - manifest に format_version / app_version / exported_at / 作品メタデータ（toc_url, title, author, site, domain, tags, novel_type 等）とファイル一覧・SHA-256。
- 共通コア: `src/transfer/`（wasm32 でビルド可能。ファイルシステム・DB・HTTP に依存しない）。
  - `build_archive(meta, files) -> Vec<u8>`、`parse_archive(bytes) -> ParsedArchive`、`plan_import(parsed, existing) -> ImportPlan`（衝突時 overwrite/skip/rename の決定）。
  - サイズ上限・エントリ数上限・パストラバーサル拒否・zip bomb 対策・manifest/ハッシュ検証。
- CLI: `narou export <target>... -o <file.zip>` / `narou import <file.zip> [--overwrite|--skip]`。
- Native Web: `GET /api/transfer/export?ids=...` はコア用の作品データ（JSON + ファイル）を返し、ブラウザ WASM が ZIP を組む。`POST /api/transfer/import` は WASM が解析・検証した結果（JSON）を受け取り、DB/オブジェクトストアへマージする。
- Worker: 同じ API。S3/ObjectStore からファイルを集め、WASM はブラウザ側で動作。サーバーは JSON の受け渡しのみ。
- WASM: `transfer_wasm` クレート（`wasm-bindgen`）。`buildZip(json)` / `parseZip(bytes)` をエクスポート。Web UI は WASM を優先し、未ビルド環境ではサーバー側 ZIP にフォールバックする。
- 競合: `toc_url` が既存作品と一致したら同一作品としてマージ。ZIP 内の作品 ID はローカル ID とみなし、取り込み先では toc_url で解決する。上書き/スキップは UI と CLI のフラグで選ぶ。

## 実装順

1. 非表示: ストア + フィルタ + CLI + Web API/UI + Worker。
2. 並列: ファミリー定義 + native 並列修正 + Web キューワーカー + Worker consumer。
3. 転送: `src/transfer` コア + CLI + native Web API + WASM クレート + Worker API + UI。
4. ドキュメント / VERSION / COMMANDS / テスト / CI。

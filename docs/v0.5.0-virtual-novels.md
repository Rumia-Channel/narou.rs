# バーチャル小説（v0.5.0 追加機能）

## 目的

「XXX その1」「XXX その2」のように分かれた小説を、`XXX` という 1 作品として
CLI / Web UI の一覧に表示し、EPUB だけ結合して出力する。実体（ダウンロード・
本文・挿絵・設定）は各小説のまま保持する。

## 表現

- **仮想小説も `novels` テーブルの通常行**として持つ（CLI / Web UI の一覧・
  検索・ソート・タグ・凍結など既存機構をそのまま使う）。
- `ncode = vs_<ID>`。`ID` は通常の小説 ID 採番（repository の `allocate_id`）を
  使い、`vs_<そのID>` を ncode とする。`toc_url` は `vs:<id>`（一意）。
  例: 既存の小説が ID 589 まで使われていれば、次に登録する仮想小説は ID 590、
  ncode は `vs_590` になる。削除しても ID は再利用しない（通常小説と同じ）。
- `novel_type` は 0、`end` は true、`general_all_no` はメンバー話数の合計。
- タグには利用者指定タグ + **`vs_<ID>`** を必ず含める。
  - 既存の hidden tag 機構で `vs_<ID>` を非表示にすれば、仮想小説行が隠れる。
  - メンバー行は「仮想小説に属する間は一覧から除外」する（後述）。
- メンバー構成と順序は在庫 `virtual_novel_members` に保存する。
  - Native: `.narou/virtual_novel_members.yaml` / SQLite `app_state`
  - Worker: D1 `app_state('inv','virtual_novel_members')`
  - 形式: `{ "<virtual_id>": [<member_id>, ...] }`（配列順 = 登録順）
- 仮想小説行は `ncode` が `vs_` で始まることで判定できる。ダウンロード・更新の
  対象からは除外し、変換だけが実体をメンバーへ展開する。

## 一覧

- 仮想小説行は通常行として一覧・検索・タグ・ソートに参加する。
- メンバー行は、どの仮想小説かに属している間は表示一覧から除外する。
  - 表示用の `NovelFilter` に `exclude_virtual_members: bool` を追加し、
    SQL では `novels.id NOT IN (SELECT member_id FROM virtual_members)` 相当、
    YAML モードでは在庫の member 集合でメモリ除外する。
  - 内部処理（update / clean / backup / export など）はメンバーも対象。
- 仮想小説を非表示にするには、`vs_<ID>` タグを `hidden` の tags に入れる。
  CLI は `narou hidden add --tag vs_1`、Web UI は非表示設定モーダルから。

## 登録・並べ替え

- メタデータは登録時に明示する: タイトル / 作者 / サイト名 / ドメイン（任意）/
  タグ（任意）。
- メンバーは既存の実小説のみ（仮想小説のネストは禁止）。
- 登録順は `virtual_novel_members` の配列順。`order` 操作で全メンバーを
  1 始まりの番号で並べ替える（全件指定）。
- 削除は仮想小説行と membership を消す。実小説・本文は消さない。

## EPUB 結合

- `narou convert vs_<ID>`（および Web UI の変換）は、メンバーを登録順に
  変換し、1 つの EPUB にまとめる。
- タイトルは仮想小説の title、作者は仮想小説の author、サイトは sitename。
- 各メンバーの先頭にメンバータイトルを見出しとして挿入し、本文・挿絵を
  登録順に連結する。
- 出力ファイル名・保存先は仮想小説の `file_title` / `sitename` に従う。
- 個別メンバーの変換結果（EPUB）は従来どおり単体でも出力できる。

## CLI / Web API

- CLI:
  - `narou virtual add --title T [--author A] [--site S] [--domain D] [--tag TAG]... <member targets...>`
  - `narou virtual list`
  - `narou virtual order <vs_ID|ID> <n1,n2,...>`
  - `narou virtual remove <vs_ID|ID>`
- Web API:
  - `GET /api/virtual_novels`
  - `POST /api/virtual_novels` (`{title, author, sitename, domain?, tags?, members:[ids]}`)
  - `POST /api/virtual_novels/{id}/order` (`{members:[ids]}`)
  - `DELETE /api/virtual_novels/{id}`
- Web UI: 一覧の行メニューから「バーチャル小説にまとめる...」、設定/専用モーダルで
  タイトル・作者・サイト・メンバー順を編集。仮想行は通常行と同じく表示・タグ・
  非表示が効く。

## 実装順

1. `VirtualNovelStore`（membership 在庫）+ 仮想行の作成/削除/並べ替え
2. 一覧の member 除外と合成行の表示（Native SQLite/YAML）
3. CLI `narou virtual`
4. Native Web API / UI
5. Worker D1 実装
6. EPUB 結合変換
7. テスト・VERSION/COMMANDS/AGENTS・CI

Narou.rs

narou.rs WEB UI ヘルプ

概要

narou.rs は小説家になろう・カクヨム等の Web 小説を管理・変換するツールです。この WEB UI からダウンロード・更新・変換・送信等の操作を行えます。

キーボードショートカット

キー動作
Dダウンロード
U更新

?このヘルプを表示

基本操作

  • ダウンロード: URLを入力して小説をダウンロードします
  • 更新: 選択した小説または全小説の更新を確認します
  • 変換: 選択した小説を電子書籍形式に変換します
  • 送信: 変換済みファイルを端末に送信します
  • 凍結: 自動更新の対象外にします

右クリックメニュー

小説一覧の行を右クリックすると、その小説に対する個別操作メニューが表示されます。

タグ

小説にタグを付けて分類できます。タグ名を右クリックすると色を変更できます。

小説データの持ち出し・取り込み

オプションの「選択した作品をダウンロード」「小説データをアップロード」から操作します。ZIP は端末内の Dedicated Worker と WASM で作成・検証します。サーバーへ ZIP 全体を送る方式ではなく、確認したメタデータとファイル本文だけを小分けで転送します。対応する WASM・安全なコンテキスト (HTTPS または localhost)・保存 API がなければ理由を表示して停止します。

通常移行 (既定)は本文・目次・利用者設定・挿絵・挿絵索引・不明な利用者ファイルを保持します。取得時の raw HTML・旧本文履歴・再生成可能と確認できた出力は既定で送りません。raw と履歴は選択画面で追加できます。通常移行は完全な backup ではありません。完全保全は同梱可能な raw・履歴・生成物も保持しますが、ライブラリ全体や DB の丸ごと backup とは異なります。

保存先が Worker の場合は raw HTML を新規保存しません。除外件数・容量・欠落する用途を確認し、同意してから開始してください。raw を省くと Native の挿絵索引再構築・orphan 判定・mitemin 移行の保守材料が減ります。現在の本文と挿絵は保持します。元の ZIP と元のライブラリは変更しません。

取り込みは全 ZIP のローカル検証が成功した後にだけ本文を送信します。登録済み作品のスキップ・上書きを事前に選び、公開前の計画でも確認します。上書きはアーカイブに含まれる内容を対象とし、含まれない既存ファイルの削除指示にはなりません。Native で取り込み中は外部アプリによる同じ作品の直接編集を避けてください。

一時停止は確定済みの受信データ・snapshot を保持します。取消は未公開分を破棄し、公開済み作品は残します。再開情報を保存できるブラウザでは、同じ ZIP を選び直して内容と確定 prefix を再検証してから続きを送信します。書き出しは同じ snapshot から新しい ZIP へ保存し直し、途中の ZIP には追記しません。別ブラウザなど再開用の秘密を失った session は、管理者として一覧から明示的に破棄できます。

進捗はローカル処理・通信・サーバー確定・公開済み作品・ZIP 出力を区別します。Firefox 等のダウンロード中継での「転送完了」はブラウザのダウンロード管理へ渡し終えた意味です。ディスクへの保存結果はブラウザのダウンロード一覧でも確認してください。
